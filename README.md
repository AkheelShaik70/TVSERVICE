# Mr. Basha Shaik – TV Service Hyderabad

A responsive React + Vite business website for an independent LCD, LED and Smart TV technician in Hyderabad.

## Included
- About, services, supported TV brands, service areas and contact sections
- Tap-to-call links for both phone numbers
- WhatsApp enquiry link
- Responsive mobile navigation and fixed mobile contact bar
- SEO title and description
- GitHub Pages deployment setup

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Deploy to GitHub Pages
1. Create a public GitHub repository named `basha-shaik-tv-service`.
2. Push this project's files to the repository's `main` branch.
3. Run `npm install`.
4. Run `npm run deploy`.
5. In GitHub, open **Settings → Pages** and select the `gh-pages` branch if prompted.
6. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/basha-shaik-tv-service/`.

If you choose a different repository name, change `base` in `vite.config.js` to `/<your-repository-name>/` before building.

## Before public advertising
- Replace the sample technician and TV photos with real, approved photos when available.
- Confirm inspection fee, service timings, service availability and all phone/WhatsApp details.
- The brand names are text wordmarks for the first version, not official brand logo artwork.
- This is an independent repair service website and does not claim authorised affiliation with any TV manufacturer.
- Add a privacy policy before adding analytics, lead forms or ad conversion tracking.

## Customisation
- Contact numbers and WhatsApp number are at the top of `src/main.jsx`.
- Working hours, language, service list and areas are also in `src/main.jsx`.
- Main colours and responsive styling are in `src/style.css`.
